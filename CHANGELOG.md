# Changelog

## 1.4.0 — непрерывное сканирование

- Добавлен переключатель **«Сканировать непрерывно»**.
- После каждого батча автоматически запускается следующий, пока в очереди есть страницы.
- Новые внутренние страницы, найденные во время обхода, тоже попадают в очередь.
- Пауза и экстренный тормоз останавливают цепочку.
- Размер батча по-прежнему 10–500 страниц; это размер одного шага, а не лимит всего обхода.

## 1.3.0 — чистый публичный релиз

- Из кода и документации убраны демонстрационные домены и примеры страниц.
- Стартовый URL по умолчанию — `https://example.com`.
- Репозиторий пересоздан с чистой историей, без прежних релизов и упоминаний.
- Функциональность 1.2.1 сохранена полностью.

## 1.2.1 — страницы вне sitemap

- При сканировании каждой страницы внутренние HTML-ссылки теперь добавляются
  в очередь, если их ещё нет в sitemap.
- Это позволяет находить страницы, которых нет в `wp-sitemap.xml`, но на которые
  ведут ссылки с уже просканированных страниц.
- Пример: страница вне sitemap, на которую ведёт ссылка с уже
  просканированной страницы, добавляется в очередь и сканируется; ссылка
  с её кнопки попадает в отчёт.
- Лимит очереди — 5000 страниц.
- Повторный проход выполняется кнопкой **«🔄 Пересканировать страницы»**.

## 1.2.0 — кнопки и пересканирование

- Извлечение ссылок не только из `<a href>`:
  - `<area href>`;
  - `form action`, `button/formaction`;
  - `data-href`, `data-url`, `data-link`, `data-target`, `data-action`,
    `data-path`, `data-route`;
  - `onclick`/`onmousedown`/`onmouseup`/`onchange`/`onsubmit` с `location`,
    `location.assign`, `location.replace`, `window.open`;
  - `iframe`/`frame`/`embed`/`object`;
  - `<meta http-equiv="refresh">`.
- В контексте строки появилась пометка источника: `[data]`, `[onclick]`,
  `[form]`, `[iframe]` и т.п.
- BFS-обход без sitemap тоже учитывает статические кнопки и data-ссылки.
- Новая кнопка **«🔄 Пересканировать страницы»**: очищает прогресс страниц
  и CSV, но сохраняет очередь и кэш HTTP-статусов.
- Ссылки, созданные JavaScript после загрузки, по-прежнему не обходятся.

## 1.1.0 — нативное окно

- EXE открывается в отдельном окне WebView2, без вкладок и адресной строки браузера.
- Окно закрывается — вместе с ним останавливается локальный Streamlit-сервер.
- Добавлено окно загрузки «Запускаю локальный сервер…».
- Добавлен `LINK_AUDIT_BROWSER=1` для запуска в обычном браузере.
- Добавлен `LINK_AUDIT_NO_BROWSER=1` для отладки без автозапуска браузера.
- Для встроенного окна путь к папке программы должен быть без кириллицы
  (например, `C:\LinkAudit`): это ограничение WebView2/.NET Framework.
- Добавлены `pywebview` и `pythonnet` в сборку.

## 1.0.0 — первый релиз

- Портативный `LinkAudit.exe` для Windows.
- Краулер sitemap + fallback, внешние ссылки, HTTP-статусы.
- GET без чтения тела, SSL-предупреждения `🔓 200`.
- Excel из 5 листов, CSV, фильтры, поиск.
- AIMD-скорость, микробатчи, пауза, экстренный тормоз.
- Тёмный интерфейс, сохранение прогресса.
- GitHub Actions и релизные артефакты.
